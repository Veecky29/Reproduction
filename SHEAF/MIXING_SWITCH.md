# 尝试二：可开关的跨通道混合（负结果）

**日期**：2026-11-27
**结论**：`h'_i = h_i + β_i · Mix(h)_i` 里的 β **在两个方向上都不动**——从 0.1 起步停在 0.1，
从 1.0 起步停在 0.97。它不是开关，是个常数。这条思路不成立。

---

## 1. 假设

尝试一（见 `NEGATIVE_RESULT.md`）表明：在固定编码器的公平对照下，
自由通道混合在 Electricity 上比纯 CI 好 **9.4%**，在 Weather 上 **0%**，在 ETT 上 **有害**。

于是提出：能不能用一个学习到的逐变量开关 β 自动选？

```
h'_i = h_i + β_i · Mix(h)_i
```

- `β = 0` → 纯 CI（`plain`）
- `β = 1` → 稠密混合（`concat`）
- 期望：ECL 上 β → 1，ETT 上 β → 0，Weather 上无所谓

**先写死预测**（跑之前）：ECL 上 β 应涨到 0.3–1.0；ETT 上应压向 0。
如果 β 该涨不涨、该降不降，卖点当场破。

## 2. 结果

β 从两端各起一次（0.1 和 1.0），同一个 rank-16 softmax 混合层，
三臂共享同一 CI 编码器、同一协议（lr 3e-4、早停 patience 3、3 种子）。

| 数据集 | plain | concat（稠密） | mix @β=0.1 | mix @β=1.0 | 收敛后 β（β=1.0 那次） |
|---|---|---|---|---|---|
| Electricity | 0.1931 | **0.1749** | 0.1937 | 0.1890 | 0.971 / 0.969 / 0.962 |
| Weather | 0.1935 | 0.1919 | **0.1797** | 0.1954 | 0.981 / 0.995 / 1.001 |
| ETTh1 | 0.4026 | 0.4022 | 0.4010 | 0.4020 | 0.956 / 0.978 / 0.969 |
| ETTh2 | **0.2965** | 0.3045 | 0.3029 | 0.3024 | 0.980 / 0.990 / 0.987 |
| ETTm1 | **0.3418** | 0.3410 | 0.3828 | 0.3811 | 0.980 / 0.982 / 0.983 |
| ETTm2 | **0.1753** | 0.1826 | 0.1762 | 0.1775 | 0.980 / 0.981 / — |

β 从 0.1 起步时收敛到 0.077–0.123；从 1.0 起步时收敛到 0.956–1.001。**两个方向都只移动 2–4%。**

## 3. 三条发现

1. **β 不学习。** 无论初值在哪，它都停在初值附近。这不是"数据不需要混合"，
   而是这个参数没有有效的梯度路径：它乘在一个已经很强的混合块外面，
   而混合块本身已经把能解释的变化吃掉了。

2. **β=1 也不等于 concat。** Electricity 上 `mix@β=1` = 0.1890，`concat` = 0.1749。
   因为 `Mix` 是 rank-16 的低秩混合，`concat` 是完整 d=128 的注意力。
   **低秩瓶颈损失掉的混合能力，靠把 β 放大补不回来。**
   这条直接推翻了设计前提（"β=1 端点就是 concat"）。

3. **低秩混合在 ETTm1 上比稠密混合差更多**：mix 0.3811 vs concat 0.3410 vs plain 0.3418。
   也就是说 `concat` 在中性/有害区至少不亏，而 `mix` 会实实在在拖累 11%。
   一个"更省算力的近似"没有资格用"更差的结果"来换。

## 4. 唯一的正向发现

把窗口统计量 `[μ_i, log σ_i]` 直接送进自身预测分支（原先只送进门控），
在所有臂上都稳定有效：

| 数据集 | 旧 plain（统计量只进门控） | 新 plain（统计量进自身分支） |
|---|---|---|
| ETTm1 | 0.3518 | **0.3418** |
| ETTm2 | 0.1771 | **0.1753** |
| ETTh1 | 0.3975 | 0.4026（略差） |
| ETTh2 | 0.2925 | 0.2965（略差） |

ETTm 上明确更好，ETTh 上略差。**这条值得单独记住**：窗口统计量对高频数据（15 分钟）
的自通道预测有用，对小时级数据则可能只是噪声。

## 5. 结论

"可开关的跨通道混合"这个机制不成立：

- 开关不学习（两个方向都不动）
- 端点不等价（低秩 ≠ 稠密，差 8%）
- 在混合有害的地方反而更糟（ETTm1 +11%）

如果还要在这条线上走，需要换掉"逐变量标量 β"这个形式——
例如按窗口动态生成 β、或者直接对混合权重做稀疏化（学习哪些边应该存在）。
但那是另一个设计，不是这次这个。
